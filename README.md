# Mangojane Integrated Funeral Management System Prototype

## Project Overview
An integrated software prototype consisting of a Flutter mobile application and an ASP.NET Core web management dashboard connected to a shared Supabase PostgreSQL backend. Designed for **Mangojane Funeral Parlor** (Welkom, Free State) to eliminate manual paper diary scheduling clashes and automate customer arrangement bookings.

- **Mobile Client:** Flutter SDK (Dart) for Android

- **Shared Cloud Backend:** Supabase (PostgreSQL, Supabase Auth, Row-Level Security)
- **Project Scheduling:** Microsoft Project
