# Mangojane Integrated Funeral Management System Prototype

## Project Description
An integrated software prototype consisting of a Flutter mobile application and an ASP.NET Core web administration dashboard connected to a shared Supabase PostgreSQL backend. Designed for **Mangojane Funeral Parlor** in Welkom to digitize funeral package browsing, automate service booking intake, prevent hearse scheduling clashes, and track burial society policy records.
